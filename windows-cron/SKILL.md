# Windows Cron

- 유저 자동화만. 시간 반복·로그인·이벤트 실행 모두 포함.
- 집: `C:\Users\Alice\Documents\윈도우 Cron`. 작업 하나 = 하위 폴더 하나.
- 실행 파일·스크립트·소스·로그·안내·작업 XML. 관련 파일 여기 모음.
- 반디집: `반디집-광고감시`. 작업 `BandizipPopupGuard-OnLaunch`. 반디집 실행 이벤트로 시작.
- WSL: `WSL-Ubuntu-실행유지`. 작업 `WSL Ubuntu Always Active`. 로그인 때 시작.
- 이동 전 등록·경로·실행 상태 확인. 작업 XML 보관.
- 이동하면 작업 실행 경로·작업 폴더·로그·해제 스크립트·안내도 갱신.
- 기존 실행 조건·권한·활성 상태 유지. 중복 작업 만들지 않음. 백그라운드 창 숨김.
- 새 경로·파일·동작 검증. 상시 작업은 검증 핑계로 임의 시작 안 함.
- 검증 끝나면 옛 위치 정리. 원본 보관 필요하면 해당 작업의 `이전버전` 안에.
- 등록됨 ≠ 실행 중 ≠ 정상 동작. 결과 구분해서 짧게 보고.
