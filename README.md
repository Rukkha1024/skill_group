# skill_group
private skill 정리해놓은 것들. 

1. **youtube-playlist-purge:** 유튜브 나중에 다시 보기 영상 쉽게 지우기. 나중에다시볼 영상 페이지에서 claude, gpt 켜서 해당 스킬 사용해서 제거하면 됨.
2. **windows-preformat-backup:** 윈도우 포맷 시 관련 백업 및 기록들 보존하도록 지시함. 시작화면·작업표시줄 설정, Office(docx/pptx) 템플릿, 파일탐색기 즐겨찾기, Notepad++ 세션·임시저장 메모, 앱 설정 폴더(XYplorer·PDF-XChange·Zotero·PowerToys), 바탕화면 아이콘 배치, 사용자 글꼴(지정한 글꼴 폴더 포함)도 `scripts/desktop-settings.ps1`로 백업·복원·검증. 전원 옵션은 포맷 후 **최고의 성능(Ultimate Performance)** 전원 구성표와 **디스플레이 끄기 없음(전원 연결·배터리 모두)**을 적용하고 현재 값을 검증하도록 지시함.
